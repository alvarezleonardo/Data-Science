Objetivos

Objetivos

■ Desarrollo de Modelos Predictivos: El objetivo principal de esta etapa es aplicar técnicas de Machine Learning

para desarrollar modelos que puedan resolver el problema planteado en el caso de negocio.

■ Evaluación y Validación: Evaluar y validar la efectividad de los modelos utilizando métricas adecuadas,

asegurando que los modelos sean precisos y generalizables.

■ Comparación y Selección de Modelos: Comparar diferentes algoritmos para identificar cuál es el más eficaz

para el problema en cuestión.

Python y Librerías de Machine Learning:

de Modelos

Proceso de Desarrollo de Modelos

Selección de Modelos

● Elige los modelos que se adapten mejor al problema planteado. Considera tanto modelos supervisados

como no supervisados.

Entrenamiento y Validación

● Divide los datos en conjuntos de entrenamiento y prueba.
● Utiliza validación cruzada para asegurar que el modelo no esté sobreajustado.

Evaluación de Desempeño

● Evalúa los modelos utilizando métricas como precisión, recall, F1 score para clasificación o MAE,

RMSE para regresión.

Optimización de Hiperparámetros

● Realiza ajustes utilizando técnicas como GridSearchCV para mejorar el

rendimiento del modelo.

Tips

■ Selección de Algoritmos: No te limites a un solo modelo; prueba

varios algoritmos y selecciona el que proporcione los mejores

resultados.

■ Interpretación de Resultados: Utiliza gráficos de importancia de

características, curvas ROC/AUC y matrices de confusión para

entender el desempeño de tu modelo.

■ Documenta Todo: Asegúrate de documentar cada paso, las

decisiones tomadas y las razones detrás de la selección de un

modelo específico.

Scripts de Modelado

Código en Python que documente el proceso de

selección, entrenamiento, y evaluación de los modelos.

Tips

Asegúrate de que el código esté bien organizado,

comentado, y que sea fácil de seguir.

Evaluación del Modelo

Informe que incluya las métricas de evaluación de cada

modelo y una justificación sobre por qué se seleccionó el

modelo final.

Tips

Incluye visualizaciones que respalden tu análisis,

como gráficos de importancia de características o

curvas ROC/AUC.

Documentación del Proceso de
Modelado

Documento que explique el proceso completo, desde la

selección del modelo hasta su evaluación y ajuste.

Tips

Mantén la documentación clara y concisa, pero lo

suficientemente detallada para que cualquier persona

pueda seguir el proceso.
