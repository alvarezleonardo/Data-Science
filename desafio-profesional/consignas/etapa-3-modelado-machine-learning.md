# Etapa III — Modelado con Machine Learning

> Fuente: [`Etapa 3 - Modelado con Machine Learning.pdf`](<../../05-desafio-profesional-etapa-3/Etapa 3 - Modelado con Machine Learning.pdf>)

## Objetivos

- **Desarrollo de Modelos Predictivos:** el objetivo principal de esta etapa es aplicar técnicas de Machine Learning para desarrollar modelos que puedan resolver el problema planteado en el caso de negocio.
- **Evaluación y Validación:** evaluar y validar la efectividad de los modelos utilizando métricas adecuadas, asegurando que los modelos sean precisos y generalizables.
- **Comparación y Selección de Modelos:** comparar diferentes algoritmos para identificar cuál es el más eficaz para el problema en cuestión.

## Contenidos y Herramientas Clave

**Python y Librerías de Machine Learning:**

- **Scikit-Learn:** para la implementación de algoritmos de Machine Learning (regresión, clasificación, clustering).
- **Pandas y NumPy:** para la manipulación y preparación de datos antes de alimentar los modelos.
- **Matplotlib y Seaborn:** para la visualización de los resultados y la interpretación de los modelos.

**Técnicas de Modelado:**

- **Modelos Supervisados:** regresión lineal, árboles de decisión, Random Forest, Support Vector Machines, etc.
- **Modelos No Supervisados:** K-Means, DBSCAN, PCA para reducción de dimensionalidad.

## Proceso de Desarrollo de Modelos

**Selección de Modelos**
- Elige los modelos que se adapten mejor al problema planteado. Considera tanto modelos supervisados como no supervisados.

**Entrenamiento y Validación**
- Divide los datos en conjuntos de entrenamiento y prueba.
- Utiliza validación cruzada para asegurar que el modelo no esté sobreajustado.

**Evaluación de Desempeño**
- Evalúa los modelos utilizando métricas como precisión, recall, F1 score para clasificación o MAE, RMSE para regresión.

**Optimización de Hiperparámetros**
- Realiza ajustes utilizando técnicas como GridSearchCV para mejorar el rendimiento del modelo.

> **Tips**
> - **Selección de Algoritmos:** no te limites a un solo modelo; prueba varios algoritmos y selecciona el que proporcione los mejores resultados.
> - **Interpretación de Resultados:** utiliza gráficos de importancia de características, curvas ROC/AUC y matrices de confusión para entender el desempeño de tu modelo.
> - **Documenta Todo:** asegúrate de documentar cada paso, las decisiones tomadas y las razones detrás de la selección de un modelo específico.

## Entregables Esperados

1. **Scripts de Modelado:** código en Python que documente el proceso de selección, entrenamiento, y evaluación de los modelos.
   > Tip: asegúrate de que el código esté bien organizado, comentado, y que sea fácil de seguir.
2. **Evaluación del Modelo:** informe que incluya las métricas de evaluación de cada modelo y una justificación sobre por qué se seleccionó el modelo final.
   > Tip: incluye visualizaciones que respalden tu análisis, como gráficos de importancia de características o curvas ROC/AUC.
3. **Documentación del Proceso de Modelado:** documento que explique el proceso completo, desde la selección del modelo hasta su evaluación y ajuste.
   > Tip: mantén la documentación clara y concisa, pero lo suficientemente detallada para que cualquier persona pueda seguir el proceso.

## Evaluación

**Criterios de Evaluación**

- **Profundidad del Análisis:** se evaluará si los modelos seleccionados y entrenados fueron los más adecuados para el problema.
- **Uso de Métricas:** evaluación del uso de métricas adecuadas para la evaluación de los modelos.
- **Comparación de Modelos:** capacidad para comparar y justificar la selección del modelo final.
- **Documentación:** la claridad y completitud de la documentación del proceso de modelado.
